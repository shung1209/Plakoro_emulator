# PlakoroDB Move Card template

The `background.png` template in this directory was sourced from:

- PlakoroDB: https://github.com/Jollto/PlakoroDB
- Source file: `database/cards/background.png`

CC BY-NC 4.0. These assets are used here for non-commercial fan-project
presentation. Move names, costs, damage, effects, and icons are rendered
dynamically by the Godot UI; finished card PNG files are not bundled.
